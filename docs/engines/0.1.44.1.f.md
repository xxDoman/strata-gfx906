## What it fixes / what it adds

Dominik's two complaints, both factual:

1. Fields that the selected path does not accept were merely **dimmed** with an explanation, which reads
   as "here is a checkbox that does the dishes" — a control that cannot work.
2. The **"engine skips this"** list was blind to the model selection: with IQ3 selected the panel showed
   `ignoring --kv q4_0` from the last `qwen35moe` start.

What changed:

- **Nothing is dimmed any more; unsupported fields are not rendered.** One source:
  `CONFIG_FIELDS` + `CONFIG_ENV_FIELDS` + `PATH_ALSO` + `PATH_FIELD_REASON` (both EN and PL), each entry
  pointing at `file:line`. The page itself holds no fields — JS renders them from
  `/api/data → paths.fields[q36|pack]`, and where the removed controls were there is now a single
  **status sentence** (`#pathstate`: "does not have …, has …" plus the source and date).
- For `q36` these do not exist on screen **and are not written to the config's env**: `--kv`,
  `--vram-reserve-mib`, `--expert-cache`, `--expert-cache-device1`, `--spec`, `--spec-min-p`,
  `--mmap-experts`, `STRATA_ROUTE_TAIL_SKIP`, `STRATA_FS_*`. For the packed path, KV / mmap / VRAM
  reserve / expert cache are alive and writable, and `--expert-vram` is not shown.
- **The "engine skips" list is tied to the start it came from**: `/api/data → ignored.model/pack` names
  the model that produced those lines; when a different model is selected the list is hidden behind a
  `<details>` labelled as historical, with its timestamp, and re-renders immediately on selection change.
- Two lying labels fixed: the geometry toggle now states the **effect** ("waive the geometry check from
  the first start") and explains OFF/ON, and the Info row states `0.1.44.1.f` (the fix *after* `.1.e`,
  same binary).

## How it was proven

- **Two probes without a GPU.** (1) `probe-konfigurator-bez-kontrolek.py`: packed A/B old vs new = **0
  differences in the whole JSON**, `path_unsupported(pack) = []`, `q36` without the flags **and without
  the dead env** keys, `fields.q36` = 6 fields with none of the packed ones, `fields.pack` = 15 fields
  without `--expert-vram`, status sentences non-empty in PL and EN. (2)
  `probe-render-pol-formularza.js`: the **same JS functions as the browser**, on a DOM stub — the `q36`
  HTML has no `#kv/#reserve/#cache/#spec/#specminp/#lowram/#dev1/#tailskip/#fs_*` (it has `#pathstate`
  and `#expertvram`), the IQ3 HTML has those fields and no `#expertvram`, and every `data-i18n` produced
  by the render exists in both EN and PL.
- **Smoke from the image** (`strata-0441f-smoke`, port 8199, no `--autostart`, `:ro` mounts, copies of the
  real config and log): phase 1 — the last start was IQ3, so `ignored.items = []` (zero `ignores --kv`
  lines); phase 2 — the log truncated to a `q36` start gave `ignored.model = Qwen3.6-35B-A3B-UD-Q6_K.gguf`
  + 3 flags, marked historical when IQ3 is selected; `POST /api/start` on a `bad` model → `blocked` with
  the verdict, zero `unknown argument`; the `/work` config copy bit-for-bit unchanged.
- **A real browser (Chromium) against the `.1.f` container**: `q36` → `ids=[ctx,expertvram,prefill,port,key,table]`,
  `#kv = null`; IQ3 → 21 fields including `#kv/#reserve/#cache/#lowram`; switching the model flips the
  skipped list from historical to current **immediately**; the panel shows one "selected now" marker and
  no leftover step from the previous selection.
- `docker build -f Dockerfile.144-1f`: every `RUN` control passed, including a **field check at build
  time** (`data1441/cfg9-fields-check.py` calls `fields_payload()` from the image and **fails the build**
  if `q36` gets a packed field or the status sentence disappears) — plus 95 anchors, 5 of them negative.

## What is NOT proven

- **No engine run on a live card** (cards forbidden). "The engine does not receive a flag it does not
  know" is proven statically and by the engine's own log; the IQ3 config with `--kv q4_0` was
  eventually run — **by Dominik at 17:51:59** — and the log shows **zero** `ignoring` lines.
- **`STRATA_FS_*` / `STRATA_ROUTE_TAIL_SKIP` on `q36`** — static proof (the `q36` path never includes
  `expert_source.cpp`); no `q36` run with those variables to watch them do nothing.
- **`--expert-vram -1`** and the **completeness of the 175-flag packed list** — as on the `.1.e` page.
- **Panel re-render** is confirmed in a browser, but no **saving** action (metadata repair, pack build)
  was clicked: the repair writes into a model file.
- The tag was never published.
