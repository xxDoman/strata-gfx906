## What it fixes / what it adds

Three changes, all in the configurator UI:

- **The engine-path block comes back as a table** (`#pathstate` as an amber `banner` + a `.ptbl` table,
  the same frame it had before) and it lists **only the exclusions** — what the path does **not** accept.
  The earlier version printed the whole list of the available fields, which Dominik called less readable
  ("no need to list what we just cannot set in this engine").
- **Full EN/PL**: all user-visible text, including server-side messages, exists as EN/PL pairs
  (`LB()` / `_lb_out()` / `_jsend()`); a build-time check (`data1441/cfg10-i18n-check.py`) **fails the
  build** when a translation is missing.
- **Panel view filter**: `POST /api/models/hide-unsupported` with persistent state in
  `/work/strata-model-actions.json` — the `Models Infos` panel can hide unsupported models, and the
  choice survives a container restart (it is not in `localStorage`).

## How it was proven

- **Four GPU-less probes**: `probe-i18n-konfiguratora.py` (290/290 keys, PL/EN symmetry, assertion of
  PL/EN pairs on server messages, the same file used in the image build); `render-bloku-sciezki.js`
  (4 renders: `q36`/pack × PL/EN, `table.ptbl` with columns, source `file:line` + date, and a
  **negative** assertion that no available-field name appears in the block); `probe-panel-filtr.js`
  (OFF = 14 rows, ON = 6 rows with 0 red, amber and green rows unchanged, a selected red model stays with
  its marker, counter 8/7); `probe-konfigurator-bez-kontrolek.py` (A/B packed and `q36` = 0 differences).
- **Smoke from the image** `0.1.44.1.g`: endpoints 200, exclusions 28/4 with PL/EN pairs,
  `POST hide-unsupported {on:true}` → `/work/strata-model-actions.json` → `docker restart` →
  `hide_unsupported = True` after the restart.
- **Build**: all **124** `&&` steps passed, including `CFG-9 FIELD CHECK: OK`, `KONTROLA
  DWUJEZYCZNOSCI: 290/290`, engine sha256 `9859791a`, rocBLAS table 108 lines, MMQ `0x26e`,
  `engine=0.1.44.1`. The launcher in the image hashes to the file on disk.
- Raw evidence kept in the packaging tree (`dowod-cfg10/`), plus a static preview of the look
  (`podglad-konfiguratora.html`).

## What is NOT proven

- **No engine run on a live card** — everything about what reaches argv is proven statically and by the
  engine's own `ignoring …` lines from the older config.
- **Descriptions of part of the packed parser's flags**: flags the launcher does not expose stand in the
  table as *undetermined — see `<file:line>`*. The row was not dropped (the table is meant to be
  complete); filling those descriptions in is separate work.
- **The filtered panel against a real scan**: the proof is a render without a browser over 14 synthetic
  models (distribution 4/0/2/8, as in the real scan) plus a live image for state persistence. No clicking
  in Chromium, no screenshot (session without a GUI).
- **The `Info` tab's long patch descriptions** (`INFO_FIXES`) are **still Polish-only** — the only place
  where switching to EN leaves Polish text. Recorded so it does not disappear.
- **Production** runs `.1.e` / `.1.f`; this image reaches it only after Dominik switches the container.
- The tag was never published.
