## What it fixes / what it adds

Same engine, new launcher. Two configurator changes:

- **Pack build as a button**, not one-off manual work: `Models Infos` gains
  `pk_plan` / `pk_build` / `_pk_worker` and the endpoints `POST /api/pack/{build,state,cancel}`, with
  `.tmp-` → rename atomicity and the button disabled with a reason when a pack cannot be built. A
  missing pack is now something the user can produce from the UI instead of a shell session.
- **The model list is gone from the Configuration tab**: the tab keeps only the selected model, and the
  row in `Models Infos` is what selects a model (one list, one source of truth).
- A guard was added for `tools/iq_pack.py` inside the image (`test -s`, `py_compile`, `--help` with
  `STRATA_GGUF_PY`) so a broken data tool cannot ship silently.

## How it was proven

- `docker build -f Dockerfile.144-1c` passed every `RUN` control, including 8 anchors for the new button
  plus a **negative** assertion (`grep -q 'id="mlist"'` must fail — the old list may not come back), and
  `iq_pack: 35755 B, --compat-bf16 visible, numpy 2.5.4`.
- **End-to-end**: the `iq2_xxs` pack (~125B MoE, uncensored IQ2_XXS) was built **by that button** through
  the API (`POST /api/pack/build` is exactly one click; `miReload` every 3 s is the progress bar), then
  compared with the same pack built by hand: **bit-for-bit identical except the path**, and registered in
  the configurator by name + the first line of `index.txt` with no change to the scoring code.
- The panel was re-read after the change: same four sections, same counters.

## What is NOT proven

- **That the engine starts and generates from `packs/iq2_xxs`** — there were no free cards (the round was
  forbidden from taking them).
- **That the button works through a real browser** — the proof is on the API (one-click endpoint + the
  polling reload); no DOM clicking was reproduced in that environment. The JS passed `node --check` and
  the button logic is inside the same `miRep()` that the metadata repair already uses in production.
- **Identical runtime behaviour versus `.1.b`** — the engine binary is literally the same
  (`9859791a`), so the only difference is the launcher (Python + HTML/JS), but there was no full UI smoke
  on the GPU.
- The `iq2_xxs` header had been touched externally (a `.hdrbak` sidecar from ~15:53); **what was changed
  in it and whether the original was correct was not investigated** — the pack is built from the current
  state of the file, which the geometry gate accepts.
- The tag was never published.
